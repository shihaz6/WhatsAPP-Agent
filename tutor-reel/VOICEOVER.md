# Voiceover (optional)

The video is caption-led and works on mute. To add a voice: record these lines over the timings below,
export one WAV the full length of the video (48 s, silence between lines), save it as `public/voiceover.wav`
and run `npm run render`. The music ducks automatically when that file exists.
